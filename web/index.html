Odlehlá kopie

Všechno, co server uloží, se průběžně kopíruje na druhý stroj, aby tohle nebylo jediné místo, kde zálohy leží. Přerušená linka se projeví jako fronta, která se po nápravě sama dožene — nikdy jako neúspěšná záloha.

Záloha konfigurace

Jeden zip s instancemi, uživateli a runnery. Hesla instancí v něm leží přesně tak, jak jsou v databázi — tedy zašifrovaná, pokud je nastavený [secrets] master_key. Klíče v archivu nejsou; ty patří k pki/ a zálohují se zvlášť (viz docs/production.md). Archiv přesto obsahuje ověřovače hesel operátorů — zacházej s ním jako s citlivým souborem.

běhy, logy ani data záloh v archivu nejsou

Obnovení konfigurace

Import nahradí celou konfiguraci obsahem archivu: co v něm není, tady po importu nebude. Nejdřív se ukáže, co se změní, a teprve pak se potvrzuje. Data záloh, běhy ani logy se nemažou.

Vyprázdnit server

Smaže všechny zálohy, dumpy a logy i celou historii běhů. Zůstanou klíče, uživatelé, instance a schválené runnery — server je hned zase provozuschopný, jen bez čehokoli nasbíraného. Tohle je jediná akce v Arcatum, která maže zálohy, a nejde vzít zpět.
